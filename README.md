# El Houcine Oussi

I'm an M.Sc. student in Computer Science at Nanjing University of Information Science and Technology (NUIST), working with Prof. Ling Tan on solar power forecasting. Before that I earned a State Engineering Degree in Information Systems Engineering from SUPMTI in Oujda, Morocco.

My research asks which learned solar forecasts actually beat strong reference forecasts, at which lead times, and when the extra accuracy changes a decision or saves money. I have two papers in preparation, one on hourly PV forecasting and one on home-battery scheduling, and I've released the BriefCensus code and data on Zenodo.

I came to research from software engineering. I've built Flutter apps, .NET Core and Django backends, and a small expression compiler in C#. I run experiments the way I'd ship code: protocols registered before results, reruns that give byte-identical output, checksummed run logs.

I'm looking for software engineering, machine learning, and applied research roles, and I can relocate. I speak Arabic, Tamazight, English, French and some Mandarin (HSK 3).
