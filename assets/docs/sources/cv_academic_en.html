Research Experience

Graduate Researcher, NUIST, Nanjing
Sep 2024 – present
  • Reference forecasts and model updating (2–12 h). Compared LightGBM, a GRU and a compact Transformer on DKASC Array 1B (Alice Springs), 31 HKUST rooftop systems (Hong Kong) and NREL PVDAQ system 9068 (Colorado). At the Hong Kong testbed, a correctly specified smart-persistence reference had half the mean absolute error of the common “any-daylight” version (0.115 vs. 0.231), which changes how much skill a learned model appears to have.
  • Value of probabilistic forecasts (day-ahead). Studied when probabilistic forecasts lower costs in home-battery scheduling, using 91,290 simulated scenarios built from 40 Ausgrid households. A scheduler using the full forecast distribution lowered cost for all 40 households.
  • Satellite and weather-forecast inputs (0.5–6 h). Forecasts for 50 Australian solar farms (AEMO data) and 94 UK virtual farms from Himawari / Meteosat imagery and issued weather forecasts. Final held-out test in progress.
  • Sky-image nowcasting (5–30 min). Tested whether ground sky images improve on a LightGBM model that uses PV history alone, on Stanford SKIPP’D. Experiments complete: sky images gave no established gain, reported as a negative result.
Methods
  • Analysis plans fixed before the final test (with recorded file hashes for the PVDAQ 9068 protocol); held-out test sets scored once.
  • Paired bootstrap confidence intervals with calendar blocks; Holm correction across lead times.
  • Checksum manifests, pinned package versions and byte-identical as-run scripts for reproducibility.
